Use an access token to sign in

The “Sign In with GitHub” button needs a separate login server that this site does not have. Signing in with an access token works the same way and needs nothing else.

  1. Close this window.
  2. On the editor page, choose Sign In Using Access Token.
  3. Paste a GitHub token that can write to this site. If you do not have one, create a fine-grained token: pick only the jessevriend-site repository and give it Contents: Read and write.
